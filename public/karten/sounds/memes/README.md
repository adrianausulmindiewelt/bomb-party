# Club Bombe – Meme-Sounds

Sieben kurze MP3-Clips aus Myinstants, für das Club-Bombe-Spiel auf maximal 3,5 Sekunden begrenzt und auf eine vergleichbare Lautheit gebracht.

Originalquellen und Download-URLs stehen in manifest.json. Originaldateien liegen intern unter data/meme-originals/.

Die MIT-Lizenz des Spielcodes ist keine Lizenz der fremden Tonaufnahmen. Die zugrundeliegenden Nutzungsrechte der Meme-Clips sind nicht verifiziert; der Download begründet keine pauschale kommerzielle Freigabe.
